# 4BIT-RELAY-CPU-SERIALVIEWER
Built and physically debugged a custom 4-bit relay CPU with ripple-carry ALU. Verified correctness via RegA/RegB+0 sweeps, A+B checks, and mod-16 Fibonacci loops. Implemented UART serial output and a Linux Python (pyserial/pygame) viewer for live graphics, including a raycasting-style demo.
